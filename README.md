# 📚 Belajar Dart Dasar

![Dart](https://img.shields.io/badge/Dart-0175C2?style=for-the-badge&logo=dart&logoColor=white)

Repositori ini berisi dokumentasi perjalanan belajar **Dart Programming Language** dari dasar. Cocok untuk pemula yang ingin memahami konsep-konsep dasar Dart sebelum melanjutkan ke framework **Flutter**.

## 📌 Materi yang Dipelajari

### ✅ **Dasar Dart**
- Variabel
- Tipe Data
- Operator

### ✅ **Control Flow**
- If-Else
- Loops
- Switch-Case

### ✅ **Function**
- Named Parameter
- Recursive Function
- Closure

### ✅ **Error Handling**
- Penanganan Error (termasuk Stack Overflow)
